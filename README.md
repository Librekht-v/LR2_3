# Лабораторная работа 2
задания выполнены для варианта 3

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Исполняемый файл: `build/lab2`.

### Go

```bash
cd go
go build -o lab2-go .
```

Исполняемый файл: `go/lab2-go`.

## Запуск

| Задание | Команда и формат ввода |
| --- | --- |
| 1 | `echo 'A+B*C' \| ./build/lab2 1` |
| 2 | `./build/lab2 2 --file data.txt --query 'SETADD apple'` |
| 3 | две строки: элементы множеств `A` и `B`, разделённые пробелами |
| 4 | две строки: последовательность и шаблон с `?` и `*` |
| 5 | последовательность целых чисел, завершающаяся `0` |
| 6 | целое число от 1 до 3999; для опыта: `benchmark N` |
| 7 | первая строка: `LRU`, ёмкость и число запросов; затем запросы `SET x y` и `GET x` |

Команды запуска одинаковы для обеих реализаций: замените `./build/lab2` на `./go/lab2-go`.

Для задания 6 реализованы методы разрешения коллизий: линейное опробование и двойное хеширование (хранение пар ключ-значение, вставка, поиск значения по ключу, удаление). Для задания 7 реализован LRU-кэш.
