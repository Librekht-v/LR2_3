# Лабораторная работа 2

Самостоятельная реализация лабораторной работы по дисциплине «Программирование». Основные индивидуальные задания выполнены для варианта 3 на C++17.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Исполняемый файл: `build/lab2`.

## Запуск

| Задание | Команда и формат ввода |
| --- | --- |
| 1 | `echo 'A+B*C' \| ./build/lab2 1` |
| 2 | `./build/lab2 2 --file data.txt --query 'SETADD apple'` |
| 3 | две строки: элементы множеств `A` и `B`, разделённые пробелами |
| 4 | две строки: последовательность и шаблон с `?` и `*` |
| 5 | последовательность целых чисел, завершающаяся `0` |
| 6 | целое число от 1 до 3999; для опыта: `benchmark N` |
| 7 | первая строка: `LRU` или `LFU`, ёмкость и число запросов; затем запросы `SET x y` и `GET x` |

Для задания 6 реализованы обе пары методов разрешения коллизий: линейное опробование, двойное хеширование, метод цепочек и хеширование кукушки. Для задания 7 реализованы оба допустимых варианта: LRU и LFU.
